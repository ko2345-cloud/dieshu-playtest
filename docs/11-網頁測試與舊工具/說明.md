# 11 網頁測試與舊工具

## 現在要開的測試

雙擊專案根目錄的 `開啟網頁測試.bat`。它會切到專案目錄，執行：

`npx expo start --web --port 8081`

瀏覽器開 `http://localhost:8081`。關掉那個命令視窗就停掉。這跑的是 `src/` 的 App，規則與關卡和手機版相同。

`package.json` 裡的 `npm run web` 是 `expo start --web`，不指定 8081。日常對玩家流程以 `.bat` 那條為準。

## 不要當成規格的舊檔

下面這些是更早的多邊型試作（可旋轉、L／T／P 等），**不是**現在的疊數規則：

| 路徑 | 為什麼不要跟 |
| --- | --- |
| `web-playtest/` | 靜態頁，顏色是黃藍紅混合，進度鍵雖同名但是 `localStorage`，和 App 的 AsyncStorage 不是同一份 |
| `tools/gen_levels.py` | 含旋轉、翻面、多邊型搜尋 |
| `tools/export_levels.py` | 把舊種子寫成網頁用關卡 |
| `tools/check_extra.py` | 檢查舊的手寫多邊型例子 |
| `tools/levels.json` | 舊輸出 |

新對話若要改規則、重產關卡、改畫面，改 `src/` 與 `tools/gen_campaign.py`，並回寫對應章節。不要為了讓 `web-playtest` 一致而把「不能旋轉、只允許矩形」改回去。

若以後刪除舊檔，在本節記一筆，並從上表拿掉。
