# 03 遊戲規則

玩家看到的說明以 `HelpModal` 為準，和判定程式一致的部分如下。

## 玩家要做的事

1. 把積木拖到棋盤上。可以重疊。
2. 拖出棋盤外面，那一塊收回（`row`、`col` 變回 `null`）。
3. 格子上的數字 = 那個圖樣（同一種覆蓋）連成一塊有幾格。
4. 積木不能旋轉。文案寫死這句。`geometry.ts` 雖有 `rotateCells`，遊玩畫面沒有呼叫它。七型方塊的每一塊是 I、J、L、O、S、T、Z 之一，關卡可以先轉成 90 度的倍數再給玩家；遊玩時一樣不能再轉。方型積木仍是實心矩形。

教學視窗只在教學第 1 關打開。

## 什麼時候過關

三個條件同時成立（`evaluate` 的 `win`）：

1. **填滿**：每一格的覆蓋至少有一個 id。
2. **都放上了**：每一塊的 `row` 不是 `null`。拖曳預覽時，正在拖的那一塊也算已放上。
3. **線索全對**：每一條線索的狀態都是 `ok`。

過關要等手指放開（`dragId == null`）才彈出。棋盤已滿、線索還沒全對時，狀態列顯示：「棋盤滿了，但數字還沒對上。試試改重疊。」

正式包的出題還要求：有重疊、每一塊至少有一格是它獨佔的。那是產生器的品質條件，不是遊玩時的額外檢查。遊玩只看上面三條。見 [09](../09-關卡產生器/說明.md)。

## 提示做什麼

按提示時：

1. 庫存大於 0 就扣 1。
2. 庫存是 0，改播獎勵廣告（目前是假的，會直接成功），不扣庫存。
3. 找到**第一塊**位置與 `solution` 不同的積木，把它放到解答座標，形狀也重置成關卡裡的本體。

一次只放對一塊。已經全對就什麼都不改。

## 教學三關在教什麼

三關都是手擺的矩形，不能轉。名稱：

1. 「重疊才對」：3×4，兩塊 2×4，最多 3 個數字。
2. 「中間那一欄」：3×3，兩塊 3×2，最多 3 個數字。
3. 「卡住那一格」：4×4，兩塊 2×2 加一塊 2×4，最多 4 個數字。

教學關的數字是區域線索裡較大的那些，不一定每一區都有數字。
