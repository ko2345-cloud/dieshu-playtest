# 07 進度與存檔

進度在 `src/data/progressStore.tsx`。整包存成 AsyncStorage 的一個 JSON，鍵名 `dieshu-progress-v1`。讀取失敗就用預設值。讀到的物件會蓋在預設值上面，所以以後新增欄位、舊存檔沒有該欄時，會落到預設。

必須包在 `ProgressProvider` 裡。`useProgress` 在 Provider 外面會丟錯。

## 欄位

| 欄位 | 預設 | 意思 |
| --- | --- | --- |
| `hints` | 5 | 提示庫存 |
| `adsRemoved` | false | 是否拿掉橫幅與插頁 |
| `levelsSinceInterstitial` | 0 | 距上次插頁又過了幾關 |
| `completed` | {} | 鍵 `p:尺寸:id` 或 `e:尺寸:id`，值 true |
| `extraUnlocked` | [] | 已買的 Extra 尺寸 |
| `tutorialDone` | false | 是否打完最後一關教學 |
| `dailySalt` | 隨機 0…1e9 | 每日抽題用的鹽，建立存檔時定死 |
| `lastDailyKey` | 無 | 型別有，沒有任何寫入 |

`ready` 只在記憶體，不存檔。首頁在讀完之前仍用預設，所以剛打開可能先顯示教學按鈕，讀完才改。

## 寫入規則

- `markComplete`：把對應鍵設成 true。不會取消完成。
- `consumeHint`：庫存 ≤ 0 回傳 false，不改數字。成功則 −1 並回傳 true。
- `addHints`：加上 n，不設上限。
- `bumpInterstitial`：已去廣告直接回傳 false，計數不變。否則 +1。滿 3 回傳 true 並把計數歸 0。未滿回傳 false。數字 3 寫在函式裡，沒有讀 `INTERSTITIAL_EVERY`。
- `resetInterstitial`：計數歸 0。目前沒有畫面呼叫它。
- `unlockExtra`：尺寸已在清單裡就不重複加。
- `unlockRemoveAds`：只把 `adsRemoved` 設成 true。
- `unlockBundle`：去廣告、提示 +100、`extraUnlocked` 設成全部尺寸（4 到 10）。
- `setTutorialDone`：設成 true，不會改回 false。
- `extraOwned`：該尺寸在清單裡，**或**清單長度 ≥ 7（`SIZES.length`）。後者是為了捆綁包一次解鎖全部。

教學完成與每日過關都不進 `completed`。
