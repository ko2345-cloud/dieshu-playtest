# 05 畫面與流程

所有畫面都沒有系統標題列。選單背景是奶油底加菱形（`GridPaper`），遊玩頁是直紋。字用系統無襯線（網頁 Segoe UI、iOS Avenir Next、Android sans-serif-medium）。網頁預覽把內容限制在寬 480 並置中，手機沒有這條限制。未去廣告時，首頁、遊玩、商店、設定底部有橫幅列。選關與每日頁沒有。

## 首頁 `/`

炭色頂欄，標題「疊數」置中白字，右上設定與商店（白字，沒有黑圓）。沒有「繼續」主按鈕。列是彩色膠囊，右側深一截。

- **教學還沒完成**：一顆膠囊「教學」，右側「開始」，進教學第 1 關。不會從上次的教學關繼續。
- **每日挑戰**：一顆膠囊，右側「今日」，進 `/daily`。
- **關卡包**：直向 4×4 到 10×10。右側是完成百分比。點了進 `/levels?size=`。

## 選關 `/levels`

參數 `size`，可選 `extra=1`。

Extra 且這尺寸未解鎖：只顯示說明與「前往商店」，不列出關卡。

已解鎖：5 顆深灰圓角方塊（白字、軟影）。完成的數字改橙色，底下有一條短橙線。頂欄中間掛牌，小字是「關卡」或「EXTRA」，大字是 `{size}×{size}`。右上設定與商店。點了進 `/play`，`mode` 為 `pack` 或 `extra`。列表長度用的是 `LEVELS_PER_SIZE`，不是 `EXTRA_PER_SIZE`。現在兩個都是 5，所以看不出來。見 [12](../12-已知差距/說明.md)。

## 每日 `/daily`

顯示日期、尺寸、這題有幾塊。開始後進 `/play?mode=daily`。過關後的「下一題」是回到上一頁，不會再抽一題。

## 遊玩 `/play`

參數：`mode`（預設 `tutorial`）、`size`（預設 4）、`id`（預設 1）。

頂欄：左標題（如 `4x4 Levels 1`、教學／每日／Extra 另有字樣），右上去廣告（`Art/remove_ads_r.png`，已去廣告則隱藏）與選單（`Art/setting.png`，回上一頁）。棋盤在標題下置中；空格是深灰，不再包白框。狀態句在棋盤下。再下一排工具圖：收回（`undo.png`）、重來（`reset.png`）、提示（`hint.png` 黃膠囊）。提示右側顯示剩餘數；剩餘為 0 時同位置改疊 `Ads.png`，不超出膠囊。棋盤高度扣掉標題、工具、托盤與橫幅後再算。

托盤是淺灰底。積木打橫最多 5 個，超過換行；全部用同一格距縮放，卡片貼合每塊外形（長條不再塞進大方塊變成細線），全部落在畫面內、不橫滑。每塊白卡片底下寫佔格數。還沒放上棋盤的是方塊圖，可以拖。已經放上的改成灰剪影，格子不消失，也不能從托盤再拖；點一下仍只改選取。從棋盤拖起來時，那一格暫時恢復成方塊圖。

找不到關卡時整頁只有「關卡還在生成中。」

過關後 `WinModal`：

| 模式 | 主按鈕 |
| --- | --- |
| 教學，後面還有 | 換成下一教學關（`replace`） |
| 教學最後一關 | 換成 4×4 免費第 1 關，並把 `tutorialDone` 設成 true |
| 每日 | 返回 |
| 免費或 Extra，還有下一關 | 同一模式、同一尺寸、id+1 |
| 已經是第 5 關 | 返回 |

過關當下就寫進度，不等玩家按下一關。教學、免費、Extra、每日都會把插頁計數 +1。見 [07](../07-進度與存檔/說明.md)。

## 商店與設定

商店 `/shop`、設定 `/settings` 的商品與廣告行為見 [08](../08-商店廣告內購/說明.md)。設定頁只顯示提示剩餘、廣告是否關掉橫幅／插頁，以及「看影片換提示在移除廣告之後仍然可用」。這兩頁和每日頁用同一套炭色頂欄與白卡片，主按鈕是橙色膠囊。
