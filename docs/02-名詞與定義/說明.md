# 02 名詞與定義

之後各節用這些詞。同一件事不要換說法。

## 格子與座標

- **格（cell）**：`[列, 行]`，都從 0 起算。列向下增加，行向右增加。
- **棋盤**：`rows` × `cols`。正式包與 Extra、每日、七型都是正方形，`rows === cols === size`，尺寸只有 4、5、6、7、8。教學關可以不是正方形（第一關是 3×4）。
- **積木本體（cells）**：相對座標，左上正規化到 `(0, 0)`。棋盤是不是正方形，跟積木是哪一種，是兩件事。
  - **方型積木**：實心矩形。可以是正方形（例如 2×2），也可以是長條（例如 1×4、4×1）。至少 2 格，最多 20 格。不能是 L、T 這類缺角的形狀。
  - **七型方塊**：只准圖上那七種，每一塊正好 4 格：I、J、L、O、S、T、Z。同一種可以轉 90 度的倍數，轉好的形狀寫進關卡。J 與 L、S 與 Z 是不同的兩種，不另做鏡射。
- **放置**：`row`、`col` 是積木左上角落在棋盤的哪一格。還沒放上棋盤時兩者都是 `null`。
- **解答（solution）**：每一塊在正確擺法下的 `{ row, col }`，順序與 `pieces` 相同。

## 覆蓋

一格的**覆蓋**是「有哪些積木蓋住這一格」，用積木 `id` 的集合表示。`id` 是該關 `pieces` 陣列的索引，從 0 起。

兩格覆蓋相同，指排序後的 id 列表一樣。只蓋住一塊、或空著，也算一種覆蓋。空覆蓋的簽章是空字串。

## 區域

從某一格出發，只走上下左右（不含對角），且鄰居的覆蓋簽章必須相同，走出的連通塊就是一個**區域**。區域大小是這個連通塊的格數。

線索上的數字 `n` 要比的就是這個大小，不是單塊積木的格數，也不是重疊層數。

## 線索

`{ r, c, n }`：在第 `r` 列、第 `c` 行顯示數字 `n`。

判定後每條線索有狀態：

- `empty`：那一格還沒有任何積木。
- `ok`：區域大小等於 `n`。
- `bad`：有積木，但區域大小不等於 `n`。

## 兩種關卡類別

`LevelCategory` 只有這兩個字。遊玩網址用 `cat`。

| cat | 意思 |
| --- | --- |
| `rect` | 方型積木。沒寫 `cat` 時也是這個 |
| `tetro` | 七型方塊 |

Extra 與每日只屬於方型。七型只有免費 5 關。

## 四種模式

`PlayParams.mode` 只有這四個字：

| mode | 意思 |
| --- | --- |
| `tutorial` | 教學關，讀 `tutorial.json`，用關卡序號，不用尺寸 |
| `pack` | 免費包，依尺寸與關卡 id |
| `extra` | 付費加關，未解鎖不能進 |
| `daily` | 當日一題，從該尺寸的後備池抽出 |

## 進度鍵

完成紀錄的鍵：

| 鍵 | 意思 |
| --- | --- |
| `p:尺寸:id` | 方型免費包 |
| `e:尺寸:id` | 方型 Extra |
| `t:尺寸:id` | 七型免費包 |

教學與每日**沒有**完成鍵。
