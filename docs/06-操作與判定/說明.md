# 06 操作與判定

判定在 `src/game/rules.ts`。幾何在 `src/game/geometry.ts`。遊玩頁把兩者接上。

## 放置

手指座標先換成棋盤格。棋盤原點用 `measureInWindow`，格距等於格寬（`gap` 在遊玩頁是 0）。點在最後一格邊緣之外不算。

拖曳預覽畫在遊玩頁根視圖裡，不是畫在視窗上。手指是視窗座標，所以要先減掉根視圖自己的 `measureInWindow`。網頁預覽內容置中時，不減這一段，積木會出現在滑鼠右邊。

放開時在 UI 執行緒立刻把預覽透明度設成 0，再量棋盤、放下或收回。不要把預覽座標動畫回原點；那樣會在棋盤旁邊留下方塊殘影。預覽容器有這塊積木的寬高，避免網頁拖曳時只清掉一條。

`tryPlace`：

- 已過關不再放。
- 每一格都要落在棋盤內，否則狀態列：「超出棋盤了，換個位置（可以重疊）。」不改位置。
- 成功則寫入該塊的 `row`、`col`。不檢查和其他塊是否重疊。重疊是允許的。

從棋盤上拖出界，該塊收回。

格的像素大小：在棋盤可用寬度，以及螢幕高減掉上下安全區、標題、工具列、狀態句、托盤預算與橫幅後剩下的高度，這兩個裡取較小值，再夾在 18 到 56 之間。棋盤內距 8。托盤格大小另算：橫向最多 5 欄、超過換行，依欄寬與托盤高度縮放，讓全部積木落在畫面內。

## 覆蓋與區域（逐步）

1. 建 `rows × cols` 的 id 列表。已放置的塊，把每一格推進對應 id。正在拖的預覽可以暫時改那一塊的座標。
2. 線索那一格若沒有 id，狀態 `empty`，大小 0。
3. 否則從該格做四向洪水填充。鄰居要進同一個區域，排序後的 id 列表必須完全相同。
4. 填充數到的格數等於 `n` 則 `ok`，否則 `bad`。

因此：兩塊重疊出的新圖樣是新區域；同一塊上圖樣相同且相連的格子才算在一起。對角相鄰不算相連。

## 選取與提示的關係

托盤點一下只改選取，不移動。已經放在棋盤上的那一格是空位，不能從托盤拖走。提示放上一塊後，選取改到那一塊。棋盤上被選中的格子畫金色框。

## 過關副作用的順序

`finishWin` 只跑一次：

1. `won = true`，成功觸覺回饋。
2. 教學且已是最後一關：`setTutorialDone`。
3. `pack` 或 `extra`：`markComplete`。每日與教學中途不寫完成鍵。
4. `bumpInterstitial`。若回傳 true，呼叫 `ads.showInterstitial()`。
