# 09 關卡產生器

**現在的出題程式只有** `tools/gen_campaign.py`。執行：`npm run gen:levels`。它會覆寫 `assets/levels/` 底下教學、免費包、Extra、每日後備。舊的 `gen_levels.py` 不是這條管線。見 [11](../11-網頁測試與舊工具/說明.md)。

改塊數、線索數、品質條件或種子之後，要重跑才會進 App。TypeScript 的 `PIECE_RANGE`、`CLUE_RANGE` 必須與本檔相同。見 [04](../04-關卡資料/說明.md)。

## 一步一步怎麼出一關

`main` 對每個尺寸 4…10，用三組種子各產 5 關：

| 包 | 種子起點 |
| --- | --- |
| 免費 | `size * 1000003` |
| Extra | `size * 2000029` |
| 每日後備 | `size * 3000047` |

每一關的實際隨機種子還會加上嘗試次數，所以同一尺寸重跑結果固定，除非改了演算法或種子。

`generate_pack` 最多嘗試 `關數 * 200` 次。不夠就丟例外，不寫出半套。兩關的「積木形狀 + 線索」相同就丟掉。

單關 `generate_one`：

1. 若塊數乘 20 仍蓋不滿棋盤，直接失敗。
2. 先盡量讓同一關每塊的高×寬都不一樣。`1×4` 與 `4×1` 算不同，因為積木不能轉。這段用 `unique=True` 呼叫 `guillotine`，最多 40 次。切出來的葉子若高×寬已出現過，這刀作廢。不用 `band_partition`。
3. `expand_rects` 把某些邊往外長一列或一行，製造重疊。每塊原心那一格受保護，別塊不能蓋住，所以每塊仍有獨佔格。盡量不重複的那段，長大時也不准變成別塊已有的高×寬。長完若不是矩形、沒通過品質條件、或最終高×寬撞了，這次作廢。
4. 若 40 次都沒有關，改成允許重複：`unique=False` 再試最多 20 次。這時 `guillotine` 切不出來才改走 `band_partition`。
5. 有一組放法後，做「正解 + 一個誘答」，再抽線索。見下一節。

## 正解與誘答

品質條件 `quality_ok`（放法必須全過）：

- 沒有空格。
- 重疊格數 > 0。
- 每一塊至少有一格只有它自己。
- 每一塊本身四向連通（實心矩形自然滿足），而且 `is_rect` 要過：實心、至少 2 格、最多 20 格。

誘答 `nudge_decoy`：形狀不變，隨機挪 1 塊或同時挪 2 塊，且仍要通過品質條件。找不到這種排法，整關作廢再試。

線索：

1. 正解的每一區，在該區最左上格放一個數字，數字等於區的格數。有空區則整關失敗。
2. `thin_clues` 從較大的區開始留數字，直到誘答**不**滿足這些數字，且數量不少于該尺寸下限。
3. 若仍多於目標數，在誘答依然失敗的前提下刪掉較不重要的數字。
4. 若少於目標數，再補回較大的區，直到目標或補完。
5. 補完後若誘答又能滿足，整關作廢。

這只保證**這一個誘答**被排除，不是證明全世界只有一組解。不要在文檔或對話裡把它寫成「已證明唯一解」。

教學關不走這套隨機。`build_tutorial` 用手寫座標呼叫 `rect_level`，再依 `max_clues` 留下較大的區。三關內容見 [03](../03-遊戲規則/說明.md)。

## 輸出

`write_pack` 寫成無空白的 JSON。正式關的 `id` 是產出順序，從 1 起。教學關另有 `name` 與 `tutorial: true`。
