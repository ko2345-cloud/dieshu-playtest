# 04 關卡資料

關卡是 JSON 陣列，由 `src/data/levelRepository.ts` 用 `require` 載入。缺檔或不是陣列時，免費包／Extra／每日池當成空陣列；教學載入失敗也是空陣列。

## 一關的欄位

| 欄位 | 必須 | 意思 |
| --- | --- | --- |
| `id` | 正式包有 | 從 1 起。載入時先找 `id`，找不到再用陣列第 `id - 1` 項 |
| `name` | 否 | 教學關有名稱。每日抽出後會改成「今日挑戰」 |
| `rows`、`cols` | 是 | 棋盤高與寬 |
| `clues` | 是 | `{ r, c, n }[]` |
| `pieces` | 是 | `Cell[][]`，每塊是正規化後的相對格 |
| `solution` | 是 | `{ row, col }[]`，與 `pieces` 等長 |
| `tutorial` | 否 | 教學關為 `true` |

`LevelData` 定義在 `src/game/types.ts`。

## 檔案放哪

| 模式 | 檔案 |
| --- | --- |
| 教學 | `assets/levels/tutorial.json`（3 關） |
| 方型免費包 | `assets/levels/{4…8}.json`，各 5 關 |
| 方型 Extra | `assets/levels/extra/{4…8}.json`，各 5 關 |
| 方型每日後備 | `assets/levels/daily_fallback/{4…8}.json`，各 5 關 |
| 七型免費包 | `assets/levels/tetro/{4…8}.json`，各 5 關 |

`loadLevel` 多一個類別。`tetro` 讀七型檔；沒寫或 `rect` 時，Extra 與免費包仍是方型。

這些 JSON 是產生器寫出來的，不要手改後又跑一次 `npm run gen:levels`，否則會被蓋掉。要改出題規則就改 [09](../09-關卡產生器/說明.md) 指的程式，再重跑。

## 每日怎麼抽

1. 尺寸：今年的第幾天（`day of year`）對 5 種尺寸取餘數。1 月 1 日是第 1 天。順序跟 `SIZES`：4、5、6、7、8，然後循環。每日只抽方型。
2. 從該尺寸的後備池取題。雜湊字串是 `YYYY-MM-DD:dailySalt:尺寸`。
3. 索引是雜湊對 `min(5, 池長度)` 取餘數。
4. 回傳時把 `id` 改成 1、`name` 改成「今日挑戰」。

`dailySalt` 存在進度裡，第一次建立存檔時隨機產生，所以**同一天、不同安裝**可能不是同一題。同一安裝、同一天是同一題。`lastDailyKey` 型別裡有，程式沒寫入，也沒有「今天已完成」。見 [12](../12-已知差距/說明.md)。

池是空的時，每日退回教學第 1 關（若教學也載不到，會是 `undefined`，遊玩頁顯示「關卡還在生成中。」）。

## 塊數與線索數（與產生器必須相同）

`src/data/constants.ts` 的 `PIECE_RANGE`、`TETRO_RANGE`、`CLUE_RANGE` 要和 `tools/gen_campaign.py` 裡的同名表一致。改一邊必須改另一邊，並在 [09](../09-關卡產生器/說明.md) 記一筆。

方型每一塊是實心矩形（含正方形與 1×n、n×1 長條），至少 2 格，最多 20 格。不能是缺角的多邊型。一塊可以跟棋盤一樣寬或一樣高，只要另一邊較短、總格數不超過 20。同一關盡量不要兩塊高×寬相同；真的切不出不同形狀時允許重複。見 [09](../09-關卡產生器/說明.md)。

任一關的線索最多 6 個。

| 尺寸 | 方型塊數 | 七型塊數 | 線索數 |
| --- | --- | --- | --- |
| 4 | 2–5 | 5–6 | 2–5 |
| 5 | 3–6 | 7–8 | 2–6 |
| 6 | 4–7 | 10–11 | 3–6 |
| 7 | 4–8 | 13–14 | 3–6 |
| 8 | 5–9 | 18–19 | 4–6 |

6×6 的方型從 4 塊起。3 塊會大到只剩整片，挪一挪小區域常常不變，數字就沒有可以著手的地方。七型每塊都是 4 格，所以塊數比方型多。8×8 從 18 塊起，不是 17：17 塊剛好只多 4 格重疊，挪不動，做不出誘答。

包內第 1 關的**塊數**靠近下限，最後一關靠近上限，中間整數內插。Extra 的塊數內插從 35% 起到 100%，所以 Extra 偏多塊。4 與 5 的線索數也這樣內插。6 到 8 的線索一律用上限 6，而且優先標在 2 到 4 格的區域上，見 [09](../09-關卡產生器/說明.md)。
