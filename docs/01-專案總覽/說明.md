# 01 專案總覽

疊數是一款直向手機益智遊戲。玩家把積木拖上棋盤，積木可以重疊。方型積木是矩形（含正方形與長條，每塊 2 到 20 格）。七型方塊只用 I、J、L、O、S、T、Z。格子上的數字不是「這塊有幾格」，而是「跟這一格**同一種覆蓋**、上下左右連在一起的區域有幾格」。填滿棋盤還不夠，數字都對上才算過關。

顯示名稱是「疊數」。套件名、網址 scheme、進度鍵都用 `dieshu`。商店包名是 `com.dieshu.app`。版本 `1.0.0`。

## 技術棧

- Expo SDK 57、expo-router、React Native 0.86、TypeScript。
- 手勢：`react-native-gesture-handler`。動畫：Reanimated。
- 進度：`@react-native-async-storage/async-storage`，鍵名 `dieshu-progress-v1`。
- 字體：Gloria Hallelujah。
- 關卡產生：Python，`tools/gen_campaign.py`。指令是 `npm run gen:levels`。
- 本機網頁測試：專案根目錄的 `開啟網頁測試.bat`，缺依賴時先安裝，再跑 `npx expo start --web --port 8081 --localhost`，並打開 `http://localhost:8081`。這是 App 的網頁版，不是 `web-playtest/`。見 [11](../11-網頁測試與舊工具/說明.md)。

目前沒有接上真實 AdMob 或商店內購。廣告與購買都是程式裡的假實作。見 [08](../08-商店廣告內購/說明.md)。

## 程式怎麼對應

| 路徑 | 職責 |
| --- | --- |
| `src/app/` | 畫面與路由：首頁、遊玩、選關、每日、商店、設定 |
| `src/game/` | 規則、幾何、方塊圖、型別。不含畫面 |
| `src/data/` | 常數、關卡載入、進度 |
| `src/ui/` | 棋盤、積木、按鈕、說明與過關視窗 |
| `src/ads/`、`src/iap/` | 廣告與商品（目前為假） |
| `assets/levels/` | 已產出的關卡 JSON |
| `tools/gen_campaign.py` | **現在**的出題程式 |
| `tools/gen_levels.py` 等 | 舊的多邊型原型，不要拿來當規格 |

路由由 expo-router 的檔名決定：`index`、`play`、`levels`、`daily`、`shop`、`settings`。根畫面在 `src/app/_layout.tsx`：手勢根、進度 Provider、把「已去廣告」同步進廣告服務、載入字體後關掉啟動畫面。

## 關卡規模（現況）

棋盤尺寸只有正方形：4、5、6、7、8。兩種類別：

- **方型積木**：實心矩形。每一種尺寸各有免費包 5 關、Extra 5 關、每日後備 5 關。
- **七型方塊**：只有 I、J、L、O、S、T、Z，關卡裡可以先轉好方向。每一種尺寸各有免費包 5 關。沒有 Extra、也不進每日。

常數寫著這是試玩包，感覺定了再加關。教學關另外 3 關，手擺，不一定是 4×4。見 [04](../04-關卡資料/說明.md)。

開局提示 5 個（`STARTER_HINTS`）。插頁廣告的意圖是每過 3 關一次（`INTERSTITIAL_EVERY`），但計數程式目前把 `3` 寫死，沒有讀這個常數。見 [12](../12-已知差距/說明.md)。
