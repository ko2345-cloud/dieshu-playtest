# 疊數製作文檔

這是本專案**唯一**的製作文檔。新對話從這裡找章節，只改對應那一節，不要另寫一份規則。

遊戲名稱：**疊數**（套件名 `dieshu`）。現況以 2026-09-19 的程式為準。文檔寫的是現在怎麼運作，不是願望清單。還沒做完的事集中在 [12-已知差距](12-已知差距/說明.md)，各章只在原處記一次。

## 新對話怎麼用

1. 先看下面的對照表，打開**一個**編號目錄裡的 `說明.md`。
2. 依該節的定義與步驟改程式。
3. 改完在該節末尾的「修改紀錄」追加一筆：日期、為什麼改、改了什麼。方案檢討先寫「待檢討」。
4. 下次再碰同一節時，先把上一筆的「待檢討」填完（是否仍與程式一致、有沒有副作用），再寫新的一筆。
5. 若新增、改名，或下面摘要變了，同時改本頁。
